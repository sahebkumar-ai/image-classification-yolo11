# YOLO11 Image Classification

This project implements image classification using the YOLO11 classification model with the Ultralytics framework. The model is trained on a custom dataset and used for image prediction and inference.

## Features
- YOLO11 classification model
- Custom dataset training
- Image prediction and inference
- Save prediction results
- PyTorch and Ultralytics based implementation

## Technologies Used
- Python
- YOLO11
- Ultralytics
- PyTorch
- OpenCV

pip install ultralytics
